About & Background

I'm an engineer by training (Industrial Engineering, ENIM Morocco), and I approach code the way I approach a broken machine: find the failing part, isolate it, fix it, prove it stays fixed. I don't do buzzwords or 12-layer architectures. I do focused Python work — debugging, data cleanup, small automations — and I hand back code you can actually read.

The scripts that cause the most damage aren't the ones that crash — they're the ones that run and quietly drop 3% of your rows. I write validation into the pipeline so that can't happen silently, and I log row counts and data types before and after every operation.
